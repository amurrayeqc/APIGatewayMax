# APIGatewayMax

APIGatewayMax is a small JavaScript command-line starter. It currently runs a deterministic in-memory processing cycle and includes retry scaffolding. It does not connect to a blockchain, database, or external API.

## Install and run

```bash
git clone https://github.com/centxyz/APIGatewayMax.git
cd APIGatewayMax
npm install
npm start -- --verbose
```

## Test

```bash
npm test
```
